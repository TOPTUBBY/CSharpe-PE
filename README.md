## 🇺🇸 English

### 📖 About The Project

**PE Semi-Auto Testing** is a Windows Forms Application designed to streamline and automate the testing processes for various Power Electronics modules. With specific testing specifications integrated for BMW, DCB, NIS, OBC, and REN systems, this tool provides a highly efficient, accurate, and user-friendly interface for engineers and operators.

### ✨ Features

- 🔋 **Multi-Module Support:** Targeted testing specs for BMW, DCB, NIS, OBC, and REN.
- 📐 **Calibration Tools:** Integrated tools for DC and DMM calibration.
- 💻 **Intuitive UI:** Easy-to-use graphical interface built on .NET Windows Forms.
- ⚙️ **Semi-Automated:** Reduces manual input and minimizes human error during testing phases.

### 🛠️ Prerequisites

Before you begin, ensure you have met the following requirements:
* Windows Operating System (Windows 10/11 recommended).
* [.NET Framework](https://dotnet.microsoft.com/download/dotnet-framework) installed on your machine.
* Visual Studio (If you want to edit and compile the source code).

### 🚀 Installation & Usage

1. **Clone or Download** the repository to your local machine:
   ```bash
   git clone https://github.com/TOPTUBBY/CSharpe-PE.git
   ```
2. Navigate to the `PE/bin/Release` or `PE/bin/Debug` folder (if pre-compiled) and run `PE.exe`.
3. Alternatively, open `PE.sln` with Visual Studio.
4. Build the solution using `Ctrl + Shift + B`.
5. Press `F5` to run the application.
6. Select the required module (e.g., BMW, OBC) from the main menu and follow the on-screen prompts to execute the testing procedures.

## 🇹🇭 ภาษาไทย

### 📖 เกี่ยวกับโปรเจค

**PE Semi-Auto Testing** คือโปรแกรม Windows Forms ที่ออกแบบมาเพื่อเพิ่มประสิทธิภาพและทำให้กระบวนการทดสอบโมดูล Power Electronics (PE) เป็นไปโดยอัตโนมัติ (กึ่งอัตโนมัติ) โปรแกรมนี้รวมข้อกำหนดการทดสอบเฉพาะระบบต่างๆ เช่น BMW, DCB, NIS, OBC และ REN เข้าไว้ด้วยกัน ทำให้วิศวกรและพนักงานฝ่ายผลิตสามารถทำงานได้อย่างรวดเร็ว แม่นยำ และมีประสิทธิภาพมากขึ้น

### ✨ ฟีเจอร์หลัก

- 🔋 **รองรับหลายโมดูล:** มีสเปกการทดสอบเฉพาะตัวสำหรับ BMW, DCB, NIS, OBC และ REN
- 📐 **เครื่องมือสอบเทียบ (Calibration):** มีฟังก์ชันช่วยเหลือในการ Calibrate DC และ DMM
- 💻 **UI ที่ใช้งานง่าย:** หน้าจอแบบกราฟิกสวยงาม พัฒนาด้วย .NET Windows Forms เหมาะสำหรับผู้ใช้งานทุกระดับ
- ⚙️ **กึ่งอัตโนมัติ:** ลดขั้นตอนการป้อนข้อมูลด้วยตนเอง และลดความผิดพลาดจากคน (Human Error) ระหว่างการทดสอบ

### 🛠️ ความต้องการของระบบ (Prerequisites)

ก่อนเริ่มต้นใช้งาน กรุณาตรวจสอบให้แน่ใจว่าอุปกรณ์ของคุณมีคุณสมบัติดังนี้:
* ระบบปฏิบัติการ Windows (แนะนำเป็น Windows 10/11)
* มีการติดตั้ง [.NET Framework](https://dotnet.microsoft.com/download/dotnet-framework) ไว้บนเครื่อง
* โปรแกรม Visual Studio (ในกรณีที่ต้องการแก้ไข Source Code และ Build โปรเจค)

### 🚀 การติดตั้ง และ การใช้งาน

1. **Clone หรือดาวน์โหลด** โค้ดลงมาที่เครื่องของคุณ:
   ```bash
   git clone https://github.com/TOPTUBBY/CSharpe-PE.git
   ```
2. เข้าไปที่โฟลเดอร์ `PE/bin/Release` หรือ `PE/bin/Debug` (ในกรณีที่มีการ Build ไว้แล้ว) แล้วรันไฟล์ `PE.exe`

4. ทำการ Build โปรเจคโดยกด `Ctrl + Shift + B`
5. กด `F5` เพื่อรันโปรแกรม
6. เลือกโมดูลที่ต้องการทดสอบจากหน้าเมนูหลัก (เช่น BMW, OBC) และทำตามคำแนะนำบนหน้าจอเพื่อเริ่มกระบวนการทดสอบ
